# Google Apps Scripts

A collection of Google Apps Scripts.

- [sheetpost](./sheetpost): add timestamped entries to a Google sheet with a
  simple HTTP request
- [google-task-dashboard](./google-task-dashboard): Google Tasks metrics
  dashboard web app
- [voice-notes-custom](./voice-notes-custom): Pebble voice notes to calendar
  and sheet, includes the sheetpost features
- see my fork of pebble apps, it contains a variation of the voice notes
  app: https://github.com/0x6d64/pebble-apps/tree/main/voice-notes
